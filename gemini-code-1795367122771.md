# SIK-DESA — Sistem Informasi Administrasi Kependudukan Desa

Aplikasi administrasi kependudukan desa berbasis **Google Spreadsheet + Google Apps Script** (Backend) dan **HTML5/CSS3/JS** (Frontend) yang siap di-hosting gratis melalui **GitHub Pages**.

---

## Langkah 1: Membuat Database Google Spreadsheet
1. Buka [Google Drive](https://drive.google.com) dan buat sebuah **Google Spreadsheet** baru.
2. Beri nama misalnya: `DATABASE_SIK_DESA`.
3. Catat **Spreadsheet ID** yang terdapat pada URL browser Anda:
   `https://docs.google.com/spreadsheets/d/` **`1aBcDeFgHiJkLmNoPqRsTuVwXyZ1234567890`** `/edit`

---

## Langkah 2: Memasang Backend Google Apps Script (`Code.gs`)
1. Dari dalam Google Spreadsheet tersebut, klik menu **Ekstensi (Extensions) > Apps Script**.
2. Hapus seluruh isi bawaan pada file `Code.gs`, lalu tempelkan seluruh kode dari file **`Code.gs`**.
3. (Opsional) Jika Anda menjalankan script secara terpisah, isi konstanta `const SPREADSHEET_ID = "ID_SPREADSHEET_ANDA";` di baris 10. Jika dibuat langsung dari menu Ekstensi Spreadsheet, biarkan kosong (`""`).
4. Klik ikon **Simpan (Ctrl+S)**.
5. Jalankan fungsi **`initializeDatabase`** satu kali dari toolbar editor Apps Script untuk membuat otomatis ke-10 sheet (`PENDUDUK`, `KARTU_KELUARGA`, `ANGGOTA_KK`, `MUTASI_DATANG`, `MUTASI_PINDAH`, `MUTASI_MENINGGAL`, `REFERENSI`, `PENGGUNA`, `LOG_AKTIVITAS`, `PENGATURAN`) beserta akun Administrator awal.
6. Klik **Review Permissions > Advanced > Go to ... (unsafe) > Allow** saat diminta otorisasi Google.

---

## Langkah 3: Deploy sebagai Web App API
1. Di editor Google Apps Script, klik tombol **Deploy > New deployment** (kanan atas).
2. Pada bagian *Select type*, pilih **Web app**.
3. Isi konfigurasi berikut:
   - **Description:** `SIK-DESA API v1`
   - **Execute as:** `Me (email Anda)`
   - **Who has access:** `Anyone` *(Keamanan dijaga melalui token sesi SHA-256 di dalam API)*
4. Klik **Deploy** dan salin **Web app URL** yang berakhiran `/exec`.

---
